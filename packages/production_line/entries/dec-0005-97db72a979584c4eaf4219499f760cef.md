## Functional exchange items mapped and described (TR88-based)

**Status:** Active

Following up on DEC-0004 (state/transition descriptions), the master station's state machine triggers have now been converted from generic ChangeEvents to ExchangeItems and allocated onto real functional exchanges, closing the loop between the state machine and the functional architecture:

- **Operator Control** (Operator's Control Machine → Manage States): `start`, `stop`, `hold`, `unhold`, `reset`, `clear` — all operator/supervisor-issued commands
- **Line Control** (Line Control's Control Machine → Manage States): `suspend`, `unsuspend` — external line-level conditions (blocked/starved)
- **Machine Status** (Manage States → Line Control's Control Machine): `abort`, `machine state complete` — internally-generated events (fault, normal completion), reported outward as status rather than commanded externally

All 9 exchange items now carry TR88.00.02-grounded descriptions (capella-fabric commit 027051ed, pushed to master), explaining what each carries, which exchange it's allocated on, and why (operator-commanded vs. line-level vs. internally-generated-and-reported).

This completes the behavioral/functional mapping for the master station ahead of converting it to a REC (see next: NOTE on port naming best practice).

**Reference:** DEC-0003 (verified state machine), DEC-0004 (state/transition descriptions), DEC-0001 (line/REC-RPL plan).
