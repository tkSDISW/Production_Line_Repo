## Adoption angle: industry-standard behavior captured in the customer's existing Capella environment

A potentially strong customer-facing aspect of this work is that the equipment-state concept does not need to be invented from scratch. An established industry reference, **ANSI/ISA-TR88.00.02 (PackML)**, provides a recognized machine-state model and command/state semantics that can serve as the behavioral foundation.

Equally important for adoption, that behavioral pattern can be represented in **Capella**, a systems-engineering tool the customer already uses. This allows the discussion to start from familiar tooling while adding explicit machine states, commands, status reporting, interfaces, and coordinated fault/recovery behavior. The combination of an industry reference model and an existing customer tool may lower the conceptual barrier to exploring the approach.
