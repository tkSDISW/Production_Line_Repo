## Decision: reference diagram style for slides / Capella state machine

**Status:** Active

Chose the Beckhoff-style PackML state diagram (surfaced via image search, "PackML: The Packaging Machine Language Driving Automation") as the starting reference for slide material and for visually mapping the state machine before building it in Capella.

**Rationale:** Capella's State Machine diagrams are Harel statecharts (nested/composite states, guard-labeled transitions), and the Beckhoff-style diagram is drawn the same way — states as boxes, labeled arrows for commands — so it translates directly into Capella notation with minimal re-interpretation, unlike a flat transition table or a Moore/Mealy circuit-style diagram.
