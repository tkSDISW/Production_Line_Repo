## purpose — Production Line Repo

**Scope:** One per repo. What this repo is for, and who it serves.
**Status:** Active

### What this repo is for

Supporting the development of a Capella system model for a small production line, with particular emphasis on capturing **machine equipment states** — specifically how a machine responds to a fault: it changes state, and must progress through a defined sequence of states to be brought back online.

This repo will hold the observations, decisions, and lessons learned generated while building that model — including research into existing state-machine standards used as a basis for the design (e.g. PackML/ISA-TR88.00.02, SEMI E10/E58, NAMUR NE107).
