## Added: Line Control's line-level fault-isolation description

Added a description to Line Control's `Control Machines` function (uuid 794c5d6f, capella-fabric commit caf38632, pushed to master), documenting its role: monitor every machine's `abort` report on Machine Status, suspend all downstream machines when one aborts (so in-flight material doesn't back up into a station that can no longer accept it), and unsuspend them once the faulted machine clears and returns to Idle.

This is the first explicit statement in the model of *why* the Suspend/Unsuspend mechanism exists at the line level, beyond the per-machine Held/Suspended distinction already documented (NOTE-0002, DEC-0004) — worth pulling into slide 1 or narration if the line-coordination behavior comes up in the presentation.

**Reference:** DEC-0004 (state/transition descriptions), NOTE-0002 (PackML state model), DEC-0010 (current model state).
